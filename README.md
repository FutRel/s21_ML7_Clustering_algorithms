# Copied from GitLab.
The main essence of the project is the study of clustering methods as a subtask of unsupervised learning and their use as a source of new features for supervised models. On the Kaggle rental listing dataset, the data was preprocessed and binary amenity features were built. K-means was implemented from scratch, fitted on the longitude and latitude features, evaluated with the Silhouette score and distortion, visualized, and its cluster labels were added as a feature to a Lasso regression; the implementation was then compared with the sklearn version. The same pipeline was repeated for DBSCAN, Agglomerative clustering and a Gaussian mixture, and for a compact set of three features, after which the algorithms were compared by complexity, speed and model quality. Additionally, approaches to centroid initialization were analysed and a way to speed up KNN with clustering was described.
